## ✨ Project Overview

**Sales Performance & Data Analysis Dashboard** is a practical Microsoft Excel project created to analyze sales, profit, quantity, customers, regions, product categories, and order dates.

The workbook combines multiple Excel analysis techniques into one project:

| 🧩 Module | 📌 Purpose |
|---|---|
| 📋 **Data** | Stores customer, sales, quantity, discount, date, and profit records |
| 📊 **Descriptive Statistics** | Summarizes Sales and Profit using statistical measures |
| 🔄 **Pivot Table** | Analyzes sales by region, product category, and year |
| 📈 **Linear Regression** | Measures the relationship between Sales and Profit |
| 🎯 **Dashboard** | Presents KPIs and executive business insights |

> 💡 **Main Excel File:** `Project - 2.xlsx`

The project is useful for **Excel data-analysis practice, business reporting, dashboard creation, statistics, PivotTables, and beginner-level predictive analysis**. 🚀


# 📈 Linear Regression

The `Linear Regression` sheet analyzes the relationship between **Sales** and **Profit**.

The regression contains **199 observations**.

### 📊 Regression Statistics

| Metric | Value |
|---|---:|
| Multiple R | 0.7736 |
| R Square | 0.5984 |
| Adjusted R Square | 0.5964 |
| Standard Error | 86.47 |
| Observations | 199 |

### 🧠 Interpretation

The model's **R Square is approximately 0.598**, meaning that about **59.8% of the variation in the dependent variable is explained by the regression model**.

The Multiple R value of approximately **0.774** indicates a positive relationship between the variables used in the regression.

### 🧪 ANOVA Result

```text
F Statistic       → 293.54
Significance F    → 6.878 × 10⁻⁴¹
```

The regression output provides a very small Significance F value, indicating that the fitted relationship is statistically significant within this dataset.

### 📌 Regression Coefficients

```text
Intercept          → -0.9782
Sales coefficient  → 0.3510
```

The positive Sales coefficient indicates that higher sales values are associated with higher predicted profit values in the fitted model.

> ⚠️ Regression shows association within this dataset. It should not automatically be interpreted as proof that increasing sales alone causes profit to increase.

# 🎯 Dashboard

The `Dashboard` sheet provides a visual **Sales Performance Dashboard** designed for quick business review.

### 📌 Main KPIs

```text
💰 TOTAL SALES
📈 TOTAL PROFIT
📦 TOTAL QUANTITY
👥 CUSTOMERS
🎯 PROFIT MARGIN
```

The dashboard calculates these KPIs directly from the `Data` sheet.

### 🧮 Dashboard Formulas

**Total Sales**

```excel
=SUM(Data!E:E)
```

**Total Profit**

```excel
=SUM(Data!I:I)
```

**Total Quantity**

```excel
=SUM(Data!F:F)
```

**Customers**

```excel
=COUNTA(_xlfn.UNIQUE(Data!B:B))
```

**Profit Margin**

```excel
=IFERROR(SUM(Data!I2:I201)/SUM(Data!E2:E201),0)
```
